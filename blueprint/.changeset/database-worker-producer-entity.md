`DatabaseWorkerProducer` takes the event record entity as an optional third constructor argument (`new DatabaseWorkerProducer(em, options, MyEventRecord)`) and creates entity instances from the events it is given before persisting them. MikroORM 7 only persists entity instances, so enqueueing a plain event object failed with "Trying to persist not discovered entity of type object", which is what every generated database worker's service does. Without the argument the producer behaves as before and callers must pass entities. Apps generated by the next CLI release pass the entity.
